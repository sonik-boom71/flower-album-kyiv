## 🌿 Зачем это

Это **личный альбом**, а не магазин. Идея — держать под рукой:

- 💰 **актуальные цены** на цветы в Киеве (и редактировать их под себя);
- 🗓 **сезонность** — что цветёт прямо сейчас, чтобы не переплачивать;
- 🌺 **символику и ароматику** каждого цветка;
- 📝 **личные заметки** и ссылки на любимых флористов;
- ❤️ **избранное** — собирать вдохновение для будущих букетов.

Открываешь утром с кофе — и за минуту понимаешь, что сейчас в сезоне и сколько стоит.

📦 **23 цветка** · **10 букетов** · **6 композиций** · реальные фото с Pexels.

## ✨ Возможности

### Базовое
- 🎨 **Две темы** — кремовая «бумажная» (по умолчанию) и тёмная «лесная»
- 📷 **Реальные фотографии** цветов (Pexels CDN, с авто-сжатием)
- 🔍 **Живой поиск** и фильтры в каждом разделе (категория, сезон, цвет, цена)
- ↕️ **Сортировка** прайс-таблицы по названию, цене и сезону
- ✏️ **Редактирование цен** прямо в карточке или таблице
- ✅ **Отметка «видела лично»** для проверенных цен
- ➕ **Свои карточки** — добавляй цветы, букеты и сборы через форму
- 📄 **Пагинация** «Показать ещё» по 12 карточек
- 💾 **Автосохранение** всего в `localStorage`
- 📱 **Адаптивный** дизайн (mobile-first брейкпоинты)
- ♿ Уважает `prefers-reduced-motion`

### Фишки 🔥
- 🧮 **Калькулятор букета** — собери букет из цветов по штукам, увидь итоговую цену и сохрани как свою композицию
- ❀ **«Что подарить сегодня»** — подбор 3 цветков по текущему сезону + совет флориста
- ⌘ **Командная палитра** (`⌘K` / `Ctrl+K`) — мгновенный поиск по всему альбому с навигацией стрелками
- ⇄ **Режим сравнения** — выбери до 3 карточек и сравни цену, сезон, аромат и символику бок-о-бок
- ⬇️ **Экспорт / импорт** — выгрузи весь альбом в JSON-файл и восстанови на другом устройстве
- ⌨️ **Горячие клавиши** для всего важного

## 🛠 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — custom properties (темы), Grid + Flexbox, `backdrop-filter`, `aspect-ratio`, `clamp()`
- **Vanilla JavaScript (ES6+)** — без единой зависимости, без сборки
- **localStorage** — вся персистентность на стороне клиента
- **IntersectionObserver** — анимации появления и подсветка навигации
- **Pexels CDN** — фотографии (бесплатная лицензия)

Шрифты — системный серифный стек (Cormorant Garamond → Georgia), моноширинный для подписей.

## 📁 Структура проекта

```
flower-album-kyiv/
├── index.html              # разметка страницы (только структура)
├── css/
│   ├── theme.css           # CSS-переменные и темы (light / dark)
│   ├── base.css            # reset, типографика, layout-примитивы, анимации
│   ├── layout.css          # masthead, hero, заголовки разделов, footer
│   ├── components.css      # карточки, фильтры, таблица, альманах, модалки, формы
│   ├── features.css        # калькулятор, палитра, suggestion, сравнение, настройки
│   └── responsive.css      # медиа-запросы (загружается последним)
├── js/
│   ├── data.js             # сид-данные (23 цветка, 10 букетов, 6 сборов) + константы
│   ├── state.js            # состояние приложения + localStorage
│   ├── utils.js            # DOM-хелперы, форматирование, доступ к данным
│   ├── filters.js          # логика фильтрации по разделам
│   ├── render.js           # рендер всех секций
│   ├── modals.js           # детальная карточка + форма добавления
│   ├── features.js         # калькулятор · палитра · suggestion · сравнение · экспорт
│   └── app.js              # темы, режимы, события и инициализация
├── assets/
│   └── favicon.svg         # ботаническая иконка
├── README.md
├── LICENSE                 # MIT
└── .gitignore
```

Скрипты подключаются по порядку зависимостей: `data → state → utils → filters → render → modals → features → app`. Никакого бандлера — браузер грузит их как есть.

## 🗃 Модель данных

Каждый цветок описывается так (`js/data.js`):

```js
{
  id: 'f3',
  plate: '03',                       // номер «пластины» в атласе
  name: 'Пион',
  nameLat: 'Paeonia',
  img: 'https://images.pexels.com/photos/32312154/...',
  priceMin: 100, priceMax: 200,      // диапазон цены, ₴
  seasons: [5, 6],                   // месяцы цветения (1–12)
  meaning: 'Процветание, счастье, богатство',
  scent: 'сильный',                  // сильный | средний | слабый | нет
  colors: ['розовый', 'белый', 'красный', 'коралловый'],
  isDried: false,                    // сухоцвет?
  note: 'Любимец флористов. Сезон очень короткий — успейте.'
}
```

Пользовательские изменения хранятся отдельно и накладываются поверх сид-данных:

```js
localStorage['kyivFloraAtlas_v2'] = {
  theme, editMode, favorites, notes, links,
  verifiedPrices,      // отметки «видела лично»
  userPrices,          // переопределённые цены
  customFlowers, customBouquets, customArrangements
}
```

## 💻 Запуск локально

Зависимостей нет — нужен только статический сервер (из-за того, что JS грузится отдельными файлами, `file://` не подойдёт из-за CORS).

```bash
# вариант 1 — Python
python3 -m http.server 8000

# вариант 2 — Node
npx serve .

# вариант 3 — VS Code
# расширение "Live Server" → Open with Live Server
```

Затем открой <http://localhost:8000>.

## 🎨 Кастомизация

**Сменить палитру** — отредактируй переменные в `css/theme.css`:
```css
:root {
  --paper: #f3ebda;   /* фон-бумага       */
  --ink:   #2a2f24;   /* основной текст   */
  --rust:  #8b3a26;   /* акцент (терракот)*/
  --moss:  #4a6447;   /* второй акцент    */
}
```

**Добавить цветок навсегда** — допиши объект в массив `FLOWERS_DATA` (`js/data.js`).
(Через кнопку «＋» на сайте — добавится только в твой браузер.)

**Поменять фото** — подставь любой URL в поле `img`. Для Pexels хватит ссылки вида
`https://images.pexels.com/photos/<ID>/pexels-photo-<ID>.jpeg` — параметры сжатия добавятся автоматически.
